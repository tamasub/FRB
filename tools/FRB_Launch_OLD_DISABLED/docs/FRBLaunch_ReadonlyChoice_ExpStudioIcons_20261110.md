## 1. 選択グリッドの説明列を読み取り専用に

選択モード（メール宛先／絵文字パレット等）の説明列を QLineEdit の `readOnly=True` で表示します。マウスドラッグで部分選択し Ctrl+C、または右クリックからコピーできます。元の `launch_choices` データは変更せず、F12によるチェック済み行の送信も維持します。一般メニュー／検索結果／Filesリストの列には変更を加えません。

## 2. Files Exp: 設定JSONのアイコンを使用

- `My Work → ZIP` 等のLaunch JSON仮想カテゴリー：元の `icon_key` をLaunchの描画関数で描画。Pageは重複アイコンを避けて従来どおり見出しのみ。
- 「ダウンロード」「F:\」等のJSONに登録された実フォルダーショートカット：元の登録Itemを検証し、`icon_key` に従ってルートアイコンを描画。
- ルート配下の実サブフォルダー：従来の通常フォルダーアイコンのまま。自動生成フォルダーにはStudio編集権限を付与しません。

## 3. 登録済み実フォルダーの「プロパティー」

右クリックした登録ルートが現在の有効なPage／Item／設定パスに一致するときのみ「プロパティー」→Studioの対象Item。元の実フォルダーのプロパティは「Windowsのプロパティ」で開けます。一般のファイル・フォルダー、ドライブ、動的カタログは従来のメニューです。物理的なフォルダーを編集せずStudio設定JSONのみを対象にします。

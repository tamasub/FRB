# FRB Launch — 公開版の設定メニュー整理（2026-11-08）

基準：`launch_app_20261108_200145.zip`

## 変更内容

1. 「Launchを隠す」「シングルクリック」から「（従来）」を削除。選択はチェックで表現。
2. 「Files Listでフォルダーを開く操作」に変更。Files第2列のみが対象で、Files Exp（第1列）とブックマークは影響しない旨をツールチップに記載。
3. 設定メニューの「実験：」を削除。Remote 1.5列・ワープ差し棒・マウス差し棒の正式な機能名を表示。差し棒UI内の「実験」表示も整理。
4. 「マウス差し棒 ▶」に「使用しない」「Files List / Exp を直接選択」「Windowsマウス方式」の排他的3択を配置。「ワープ差し棒 ～ぐりぐりスピナー～（上下追従）」は同じメニューの独立したチェック項目として維持。

## 互換性・既存操作

- 既存のQSettingsキー（`experiment_mouse_pointer_rod`、`experiment_mouse_pointer_rod_windows`、`experiment_mouse_pointer_rod_smart`、`experiment_remote_15_column`）は**変更しない**。内部キー名の `experiment_` は保存データとの互換性のため残す。
- OFFの場合は「使用しない」、ON+Windows方式なら「Windowsマウス方式」、ON+直接選択なら「Files List / Exp を直接選択」のチェックが付く。
- 「使用しない」を選ぶと差し棒はOFFになり、Windowsクリック方式もOFFへ戻す。上下追従のチェック設定は記憶したまま、差し棒ON時に再び有効になる。
- マウス操作の機構、Remoteのぐりぐり、手裏剣スクロール、Files操作の実装は変更しない。

## Windows実機での最終確認

1. 設定メニュー（Launch本体とRemoteの両方）から右にサブメニューが展開すること。
2. OFF → 直接選択 → Windowsマウス方式 → OFFの順に選び、チェックが常に1つ、操作が既存と同じであること。
3. 上下追従をONにしてから差し棒をOFF→ONにしても設定が維持されること。
4. Launch再起動後も選択状態が保存されること。
5. Folder clickのシングル／ダブルがFiles Listだけに作用すること。

Python構文チェックとQt非依存の操作テストは実施。Windows実機の表示・操作については未検証（この環境にPySide6なし）。

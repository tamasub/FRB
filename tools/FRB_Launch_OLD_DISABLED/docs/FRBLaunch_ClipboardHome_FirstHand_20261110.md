# FRB Launch — クリップボード通知／HOME復帰／手裏剣1の手（2026-11-10）

## 対応

1. `ClipboardCopy` および `SendKey` でクリップボードへ書き込めた直後に、既存の一時ステータスバーへ `ℹ️ クリップボードにコピーしました：<項目名>` を表示。日付・定型文／メール宛先・絵文字を含む。`SendKey` の貼り付け成功を保証する文言にはしていない。
2. 展開表示モードで、絵文字・メールの選択画面等によりFilesが一時的に隠れている場合、HOMEで設定されたFilesワークスペースへ復帰し、従来のExp先頭行選択／枝の折畳みを実行。明示的なClassic表示時のHOMEは従来動作を維持。
3. 手裏剣「1の手」の割当は、既存の `items` 配下の `shuriken_enabled` を使用。`shuriken_order` / `item_id` 順で先頭4件のみ表示・実行し、5件目以降は読み捨て（データは削除しない）。5件以上の登録による件数エラーは廃止。`shuriken_direction` 未設定なら登録数に合わせた1〜4方向へ自動割当。明示的に設定された方向は維持。

## 注意

- 既存のユーザー設定JSONは変更していない。4件の既存手裏剣項目があるため、新たな項目を1の手へ表示したい場合は、既存項目の登録をOFFにするか、新しい項目の表示順を小さくする。
- Studio側の詳細編集画面に追加した「手裏剣・一の手に表示」「表示優先順」「フリック方向（空欄は自動）」「専用」「特殊操作ID」を編集し、保存後Launchで再読込する。
- Windows実機 GUI テストは未実施（Qtは検証環境へ未導入）。クリップボード通知・HOME復帰のロジック、4件制限・自動方向の専用テストはPASS。

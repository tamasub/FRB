## 変更
1. **カテゴリーのアイコン選択**：既存 `ConfirmationInputGuard` が `QComboBox` のクリックとホイールを背景イベント扱いしていたため、ネイティブ入力として通す。コンボのドロップダウン（別のQt.Popupウィンドウ）も通す。ぐりぐりの保存・キャンセルは従来どおり。
2. **説明欄**：簡易編集 `QPlainTextEdit` を白背景＋暗色文字に固定する。3項目（アイコン、タイトル、説明）のまま。パス編集は無し。
3. **実ファイルDrop**：設定JSONのFiles Listで、ファイル・URLなど既存の末端アイテム行に重ねて外部ファイルをDropした場合、その行を登録先と解釈せず、現在表示中の親カテゴリへAddする。カテゴリ行へのDropは従来どおりそのカテゴリの配下。設定JSONのMove用MIMEと区別、実ファイルシステム上のMoveは行わない。
4. **検索ボタン**：Filesヘッダーにある虫眼鏡の検索履歴ボタンを非表示。グローバル検索、Files List検索、ショートカット経由の処理は維持。
5. **Drop目印**：Files Expのルート余白に `～ フォルダー Drop エリア ～` を薄いグレーで表示。余白がない場合は非表示。ラベルはマウス/Dropイベント透過。

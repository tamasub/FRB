## 対象と判断
- 基準: `launch_app_20261112_102350.zip` のみ。
- Studioくん側は変更しない。
- `Files Exp` ルート余白のコンテキストメニューから「カテゴリーフォルダーを作成...」を除去。「既存フォルダーを登録...」は維持。設定JSONフォルダー配下でのカテゴリー作成は維持。
- `FRB ぐりぐりクリックRunner` はリモコン非表示でも、実際に開いているQMenu上のホイール操作を有効にする。リモコンのパッド操作はリモコン表示時のみ。

## 保証・制約
- Files Expルートへの新規登録は従来どおりフォルダー専用。ファイル・URLは登録できない。
- 既存のAdd / Update / Delete / Moveや実ファイル操作経路は変更しない。
- ナビゲーションのコマンドは既存 `remote_command` を再利用。LISTメニュー起点のみ、操作前にLISTを操作対象へ戻す。
- メニュー上でのホイール選択→クリックは、QActionの既存実行に接続し、画面上の他ウィジェットへのホイール入力を奪わない。
- Windows実機のPySide6描画・ポップアップ・ホイールイベントはこの環境では未受入。

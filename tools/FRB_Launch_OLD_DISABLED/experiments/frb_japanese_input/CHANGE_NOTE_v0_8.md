# FRBかな v0.8 — IME候補一覧のための余白

## 観測
FRBかな内のQLineEditでWindows IMEの候補を表示できたが、候補ウィンドウが下のかなキーを覆い、次の文字が入力しにくくなった。

## 変更
- 入力欄と3×4かな盤面の間に、候補ポップアップ用の空白を確保。初期値260px。
- 下部の「間260」から0/120/200/260/320pxに変更可能。
- 全4段階の小型キーボード幅、10pxフリック判定（Remote preset）、IME送信方式を変更しない。
- 実験フォルダーは従来どおり `experiments/frb_japanese_input/`。

## 実機で確かめること
1. Windows IMEを「あ」にし、FRB入力欄へフォーカスを置く。
2. 「たまい」などを入力し予測候補が出ても「あ・か・さ」のキーを引き続きクリックできるか。
3. 余白260pxを200→120へと縮め、候補が重なり始める境界を観測する。
4. 画面下端に配置した場合、IMEが候補を上向きに出すなど表示が変わる場合がある点に注意する。

## テスト
Pure Pythonの自動テストを追加。Windows GUI / 予測候補の実配置は未検証。

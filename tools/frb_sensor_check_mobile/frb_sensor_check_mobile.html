ナイキスト周波数とは、サンプリングしたデータから元の信号を正確に再現できる最大の周波数の目安です。基本的には「実効サンプリングHz ÷ 2」。ただし、スマホのdtばらつきやOS側の処理があるため、実用上はさらに低めに見ます。

1. Time Series

まずは「取れているか」「周期が安定しているか」を見る窓。

2. Band Timeline Investigate Scale

低周波スマホ向け。20Hz刻み中心で帯域エネルギーの時間変化を見る。スマホ版の主役候補。

3. Flux

フレーム間のスペクトル変化量。dtが荒いと暴れるので、まずは補助窓扱い。

4. Peak Timeline

青●＝加速度センサーFFTから検出した主ピーク候補。点が大きく濃いほど、その瞬間に強く出たピーク。背景の帯は期待Hzの目安。狙った周波数帯に主ピークが乗るかを見る窓。

5. Spectrum Snapshot

簡易FFT。端末の実効サンプリングHzの半分より上は、ナイキスト周波数を超えるため正しく見えません。
FRB Lite #0 の見方

このページの目的は「スマホでFRB本測定をすること」ではなく、スマホ内蔵センサーがどこまで振動を見られるかの境界確認です。 見えたものを喜び、見えなかったものも境界として記録します。

推奨順：実効Hz → dtばらつき → ナイキスト周波数 → Time Series → Peak Timeline → Band Timeline → Flux → Spectrum。FFTだけを先に信じないこと。

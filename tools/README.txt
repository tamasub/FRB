FRB Studio mdViewer V2.1 Slash Command Edition

追加内容:
- Editorモードで行頭に / を入力するとQiita風の挿入メニューを表示
- /code または /コード でコードブロック挿入
- /table または /テーブル /表 でMarkdownテーブル挿入
- キーボード操作: ↑↓で選択、Enter/Tabで挿入、Escで閉じる
- 補助ボタン: Code / Table をエディター下部に追加
- fmPublished の重複idを修正

使い方:
1. mdViewerV2.1.html をブラウザで開く
2. Editorモードへ切り替える
3. 行頭で / を入力

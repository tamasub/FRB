# v0.15.5.3.1 Target Context / Main Context Compact UX Report

## 目的

v0.15.5.3 で実装した対象文脈Detailパネルについて、実画面確認で見えたUX上の違和感を補修する。

- 対象文脈パネルはDetail上部で横幅いっぱいを使う。
- 対象文脈は主文脈と同じく、通常は要約表示だけにして、ボタン押下で明細を開く。
- 主文脈・対象文脈の縦方向余白を減らし、コンパクトにする。

## 方針

主文脈・対象文脈はいずれも「文脈の入口」であり、本文より前に置く。ただし常時明細を展開すると画面を圧迫するため、通常時は件数・必須・停止などの要約だけを表示し、必要な時だけ展開して編集する。

## 更新内容

- `targetContextDetailPanelExpanded` の初期値を `false` に変更。
- データ読み込み時も対象文脈Detailパネルを閉じた状態に初期化。
- 対象文脈パネルをDetail Form内で `grid-column: 1 / -1` にし、横幅いっぱい表示に変更。
- 対象文脈の「追加」ボタンは展開時だけ表示するようにし、通常時の要約行をコンパクト化。
- 主文脈・対象文脈のパネル、バッジ、テーブル、入力欄、フッターのpadding/marginを縮小。
- index.html のキャッシュバスターを更新。

## 確認観点

- Detailを開いた直後、対象文脈は要約のみ表示されること。
- 「対象文脈を確認」を押すと明細が展開されること。
- 対象文脈パネルがDetail Formの横幅いっぱいを使うこと。
- 主文脈ヘッダーが従来より縦方向にコンパクトであること。
- 対象文脈の追加・削除・反映の既存動作を壊さないこと。

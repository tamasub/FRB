## 学習フロー

1. 設問一覧から1件を開く。
2. 正答を見る前に「回答前の自分の前提」と「回答前に作った問い」を書く。
3. 自分の回答・理由・自信度を入力する。
4. `正答表示` を `公開` に変更する。
5. Expected / Actual / Diff を確認する。
6. 差分への違和感や追加質問を会話欄へ追記する。
7. `理解判定`、`復習優先度`、`次回復習` を更新する。
8. 選択行の Markdown AI Prompt を使い、AIへ差分分析と次の問い生成を依頼する。

## 画面設計の狙い

- Gridは「今どこを学ぶか」を選ぶ場所。
- Detail上部は設問根拠（対象文脈）。
- 設問カードは読み物として表示。
- 正答は手動で公開するまで隠す。
- 自信満々の誤答と、自信のない正答を検索・優先復習できる。
- 回答履歴と学習判断ログをData JSONに残す。

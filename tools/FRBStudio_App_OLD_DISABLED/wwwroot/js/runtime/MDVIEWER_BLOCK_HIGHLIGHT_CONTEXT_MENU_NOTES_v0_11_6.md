# mdViewer v0.11.6 — Preview Block Highlight Context Menu

目的:
- Markdownプレビュー上のブロックを右クリックし、「ハイライト」で一時的に黄色背景にできる。
- コメント/注釈/AI操作など、将来のブロックアクション体験を軽く確認するための試作。

仕様:
- 対象は `data-md-line` が付与されたプレビューブロック。
- ハイライト状態はDOM上のclassだけで保持し、Markdown本文・JSON・ファイルには保存しない。
- 再描画、再読込、モード切替、編集反映でハイライトは消える。
- 右クリック時のカレントブロック認識は既存のMarkdown行アンカーを利用する。

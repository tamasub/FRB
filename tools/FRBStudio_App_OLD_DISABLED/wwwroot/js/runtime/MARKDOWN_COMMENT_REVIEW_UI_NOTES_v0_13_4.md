# v0.13.4 Markdown Comment Review UI Notes

## 目的

v0.13.3で導入した `.comments.json` のSidecarコメントを、本文上のバッジだけでなく、左サイドバーの一覧UIとしてレビューできるようにする。

## 実装内容

- 左サイドバーに「コメントレビュー」パネルを追加
- 未解決 / 全件 / 解決済 のフィルターを追加
- コメント一覧から対象Block / TableCellへジャンプ
- 対象へスクロールし、一時ハイライトを表示
- コメントの解決 / 再開、本文編集、削除を追加
- 変更後は既存のSidecar保存処理を使って `.comments.json` へ保存
- 本文Markdownにはコメント情報を混入させない

## 方針

v0.13.4は大きなレビューシステムではなく、まず「付けたコメントを見失わない」ためのMVPとする。

- 付箋を貼る: v0.13.3
- 付箋を一覧管理する: v0.13.4
- 保存安全性 / RoundTrip確認: v0.13.5

## 確認ポイント

1. Sidecarコメントを追加すると、左のコメントレビュー一覧に出る
2. 一覧クリックで対象Block / TableCellへジャンプする
3. 解決を押すと本文上のバッジから消え、解決済フィルターに移る
4. 再開すると未解決に戻る
5. 編集 / 削除後に `.comments.json` が更新される

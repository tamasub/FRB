# FX Studio / HSI Simulation Rule v0.26 — 最小要約

> 過去チャート上の判断再現用。売買推奨ではない。

## 共通原則

```text
NORMAL / EXPANSION / EXPANSION_LITE
= 同じ市場を観察する独立した別人
```

共有するのは確定足・Swing・Dow・T3・HSI・Cycle等の市場事実だけ。
他LaneのEntry / Position / Close / 損益 / Opportunity / Anchorは知らない。

## NORMAL v0.24

```text
新しいM5 Dow Confirmation
＋ H4/H1 T3整合
＋ H1 Cycle Late除外
＋ Normal AnchorからR2以上
→ Normal Entry
```

Entry前Dow崩壊でConfirmation / Anchor / Opportunity / R2履歴を失効。
Entry後Dow崩壊だけではCloseせず、Anchor / Target / Stopを固定維持。
H4同方向波R4以上では新規NORMAL Entry禁止。

## EXPANSION_LITE v0.26

### Episode / Anchor

```text
M5 Dow Confirmation
→ Lite Episode開始
→ previous SwingをLite HSI Anchorとして固定
```

```text
後続M5 Dow崩壊
同方向Dow再確定
→ Anchor変更なし
→ Episode継続
```

反対方向Expansion Episode成立時だけ、新しいEpisode / Anchorへ切り替える。

### Entry

```text
Lite Episode ACTIVE
＋ H4 CloseがEntry方向T3側
＋ H1 CloseがEntry方向T3側
＋ H1 Cycle起点から14本以内
＋ 固定AnchorからValid R3 Touch
→ Entry
```

Valid R3 Touch:

```text
直前M5 CloseがR3内側
＋ 現在足がR3へ到達・通過
```

新しいDow ConfirmationはEntry直前条件ではない。

### T3不整合時のR3

```text
R3 Touch
＋ T3不整合
→ Entryしない
→ Opportunityを消費しない
→ R3内側復帰後の再タッチ待ち
```

R3外側で後からT3が整っただけではEntryしない。

### Cycle

```text
elapsed <= 14 → 監視継続
elapsed > 14  → Initial Entry EXPIRED
未解決        → WAIT
```

### Add-on / Target

```text
R3.5 / R4 / R4.5で各1回Add-on
固定AnchorからR5で全Close
```

### Anchor Exit

```text
Long  = M5 Low < 固定Anchor
Short = M5 High > 固定Anchor
→ 全Close
```

Anchor ExitはLiteのHard StopとしてEntry直後から有効。

### T3 Exit

```text
Entry後1〜3本目
→ T3 Exit無効

Entry後4本目以降
Long  = M5 Close < M5 T3
Short = M5 Close > M5 T3
→ 全Close
```

High / LowのヒゲだけではT3 Exitしない。

### Structural Break

```text
M5 Dow Structural Break
→ Shadow / Trace記録のみ
→ Closeしない
```

### 1 Episodeの回数

```text
1 Expansion Episode
= 最大1 Initial Entry
```

同一Episode内ReEntryは未定義・無効。

## EXPANSION

独立Laneとして保持。具体的Entry / Add-on / Exitは未定義。
NORMALやLiteのルールで補完しない。

## v0.26の核心

```text
DowはLite起点を生む。
その後の小さなDow崩壊では起点を動かさない。

T3はEntry環境を見る。
R3は内側から外側へのValid TouchでEntryを押す。

Entry直後3本はT3ノイズを許容する。
4本目以降はM5 CloseでT3 Exitする。
旧Structural Exitは観測だけに戻す。
```

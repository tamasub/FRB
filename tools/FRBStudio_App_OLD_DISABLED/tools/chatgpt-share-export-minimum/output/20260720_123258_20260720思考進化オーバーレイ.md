## 1. 「自分の1日」を構造化する：パーソナル・ライフ・ログ JSON

普段何気なく過ごしている自分の行動や思考、部屋の環境などを独自スキーマでJSON化し、可視化や分析をしてみるテーマです。

* **探索ポイント:**
* mood_level（気分）やfocus_score（集中度）と一緒に、室温や作業時の「BGMのBPM」「キーボード打鍵数」などをログ化。
* 「コーヒーを飲んだ15分後に集中度が上がる説」などを自分のデータで検証。

* **ここが面白い:** 自分が「APIサーバー」になった気分で、自分のライフスタイルをクエリできるようになります。

json
{
  "timestamp": "2026-07-20T11:00:00Z",
  "activity": "brainstorming",
  "environment": {
    "temperature_c": 26.5,
    "noise_level": "moderate"
  },
  "mental_state": {
    "excitement": 85,
    "caffeine_mg": 100
  }
}

## 2. 街の「空気感」をWebから掘り起こす：オープンデータJSON巡り

自治体や気象庁、国際機関が公開している「オープンデータAPI」から、誰も着目していない変な相関関係を探すテーマです。

* **探索ポイント:**
* **気象庁のJSON API**（実は隠れたWeb APIがあります）から「風向き」と「地域のイベント/交通データ」を取得。
* 「雨の日の特定の時間帯だけ跳ね上がるデータ」や「ある地域の街頭犯罪と街灯の設置数の相関」などを探る。

* **ここが面白い:** グラフ表示や地図マッピング（GeoJSON）と連携させると、見慣れた街の「裏側のデータ構造」が見えてきます。

---

## 3. 「プロンプト Engineering & 思考プロセス」のグラフJSON化

AIとのやり取りや、自分の思考の「分岐」を木構造（Tree）やグラフ（Graph）のJSONデータとして記録・可視化するテーマです。

* **探索ポイント:**
* 1つの課題に対して「どう試行錯誤して解決に至ったか」のノードとエッジをJSONで定義。
* 成功した思考ルートと、行き詰まった思考ルート（デッドエンド）をJSON構造で比較。

* **ここが面白い:** nodes と edges をつないでD3.jsなどでノードグラフ化すると、自分の脳内マップを可視化するような圧倒的ワクワク感があります。

json
{
  "nodes": [
    {"id": "idea_1", "label": "センサで何か測る", "status": "rejected"},
    {"id": "idea_2", "label": "JSONで未知のデータ構造を作る", "status": "active"}
  ],
  "edges": [
    {"source": "idea_1", "target": "idea_2", "relation": "pivot"}
  ]
}

## 4. レトロゲームの「セーブデータ/構造解析」ごっこ

完全オリジナルの「架空のRPGのセーブデータ」や「架空のダンジョン構造」をJSONだけで定義してみるテーマです。

* **探索ポイント:**
* 「100階建てのランダム生成ダンジョンの各部屋の接続関係」をJSONだけで表現してみる。
* 複雑な状態異常の優先度や、アイテム同士の合成ルールをJSONスキーマ（JSON Schema）で厳密に設計する。

* **ここが面白い:** 画面（UI）を作らなくても、**「JSONの設計だけでゲームシステムが完璧に成立している状態」** を構築するパズル的な面白さがあります。

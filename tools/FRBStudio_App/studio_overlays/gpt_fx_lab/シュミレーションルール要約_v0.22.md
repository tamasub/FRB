# FX Studio / HSI Simulation Rule v0.22 — 最小要約

> 過去チャート上の判断再現用。売買推奨ではない。

## 共通原則

```text
NORMAL / EXPANSION / EXPANSION_LITE は条件・起点・建玉・Exitを混ぜず、同時並列で独立評価する。
共有可能なのはローソク足・T3・HSI境界・Cycle位置・確定Dow点などの観測事実だけ。
Confirm bars と Entry許可本数は別物。Entry Window初期値は WEEK20 / DAY45 / H4 14 / H1 14 / M5 20。
現時点でEntry Windowを使用するのはExpansion-LiteのH1 14本以内だけ。
```

## NORMAL

```text
Entry条件:
H4・H1のT3方向と終値位置がEntry方向へ整合
/ H1 Cycle Lateではない
/ 新しいM5 Dow Confirmation
/ 採用M5 HSI起点からR2以上
/ NORMAL建玉なし。

Entry価格:
Dow突破条件とR2条件が初めて同時成立する価格。
1 Confirmation IDにつき最大1 Entry。

Target:
Entry地点より先の次HSI境界。到達で全Close。

Stop:
Entry時の採用M5 HSI起点。
M5 High/Lowで判定し、Targetと同一足ならStop優先。

Close後:
使用した起点とOpportunityを破棄し、新しいM5 Dow Confirmationを待つ。
```

### NORMAL H4 R4 Guard（v0.22）

```text
Entry方向 = H4現在波方向
AND H4現在波のHSI進行度 >= R4
→ 新規NORMAL Entry禁止
```

```text
LONG  + H4現在波=UP   + H4上昇波R4以上 → Entry NG
SHORT + H4現在波=DOWN + H4下降波R4以上 → Entry NG
```

```text
R4未到達:
  本Guardだけでは禁止しない

R4到達または超過:
  新規NORMAL Entry禁止
```

Day Trendは条件に使用しない。  
H4 Wave AnchorはH4現在波の採用済み確定高値・安値であり、M5 Normal HSI Anchorとは別物。  
Guard拒否時は同じ `dow_confirmation_id` を再利用しない。

```text
Reason Code:
NORMAL_H4_SAME_DIRECTION_R4_ENTRY_BLOCKED
```

禁止:

```text
通常Add-on / Partial Close / Runner / 同じConfirmation ID再利用
/ H1 Cycle Lateでの新規NORMAL Entry
/ H4同方向波R4到達後の新規NORMAL Entry
```

## EXPANSION_LITE

```text
Entry条件:
H4・H1終値がEntry方向のT3側
/ 方向別H1 Cycle起点から14本以内
/ M5 Dow確定
/ 採用Dow HSI起点からR3タッチ。

成立順:
R3タッチ後にDow確定、またはDow確定後にR3初タッチの両方を許可。

Add-on:
R3.5 / R4 / R4.5タッチで各1回。上限R4.5。

全Close:
R5タッチ
/ M5 High・LowによるT3逆抜け
/ 新しいM5 Dow点確定による構造破綻
/ M5 High・Lowによる採用HSI起点逆抜け。
```

v0.22のNORMAL R4 GuardはEXPANSION_LITEへ適用しない。

v0.21 Guardは維持する。

```text
Entry方向=SHORT
AND Day Trend=UP
AND H4現在波=DOWN
AND H4下降波のHSI進行度>=R5
→ EXPANSION_LITEの初回Short Entry禁止
```

## EXPANSION

```text
独立Rule Laneとして並列評価するが、具体的Entry / Add-on / Exit条件は未確定・未実装。
未定義部分をNORMALまたはEXPANSION_LITEの条件で補完しない。
v0.22 NORMAL R4 Guardは自動適用しない。
将来Entry仕様を実装する際、v0.21 Day Up / H4下降R5 Short Guardを独立評価する。
```

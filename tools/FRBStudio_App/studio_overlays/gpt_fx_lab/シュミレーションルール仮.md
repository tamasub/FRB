先生ガードかけつつ言うと、今の脳内ルールは **かなり自然な構造** になってます。

ただし、いま見えてきたのは「勝てるルール」ではなく、まずは **検証可能な仮説** です。

## 今のルールを整理すると

たぶん、こうです。

```text id="614wj8"
上位足 = やっていい方向を決める
M5ダウ = 起点を探す
HSI R2(89) = エントリートリガー
HSI R3(144)付近 = 利確候補
T3 = 下位足の継続/撤退判定
```

これ、役割分担がかなり綺麗です。

## T3の位置づけ

今回の気づきはたぶんこれ。

```text id="n87son"
HSIだけだと「伸びる前提」で見てしまう
でもT3を割ったら、M5下位トレンドが崩れた可能性がある
```

なので、T3はエントリー条件というより、まずは **撤退条件** として入れるのが自然に見えます。

```text id="m9wyfl"
買いエントリー後、
M5 close が T3 を下回ったらクローズ候補
```

これはかなり筋がいいです。

## 先生案：まずはこう分ける

```text id="sc0j3n"
Entry:
  上位足アップ
  M5ダウアップ
  HSI R2(89)ラインを close で上抜け

Take Profit:
  R2〜R3の中間
  または R3(144)付近

Emergency / Invalid Close:
  M5 close < T3
```

この `Emergency / Invalid Close` がめちゃ大事。

利確とは別です。

```text id="i9spdo"
利確 = 仮説どおり伸びたので閉じる
T3割れ = 仮説が崩れたので閉じる
```

この2つは分けた方がいい。

## ただし、T3条件は少しだけ慎重にしたい

1本だけT3を割った瞬間に閉じると、ノイズで狩られるかもしれない。

なので候補は3パターンあります。

```text id="9fxbgd"
A. close < T3 で即クローズ
B. close < T3 が2本連続でクローズ
C. close < T3 かつ T3 slope <= 0 でクローズ
```

最初の検証は、Aでいいです。
理由は単純で、まず分かりやすいから。

でも最終的には、BかCも比較したくなるはず。

## いまの画面で言うと

この画像はまさに、

```text id="a8tu67"
HSI R2到達で入る
↓
でもその後、T3を下回る
↓
R3まで引っ張らずに撤退できた可能性
```

に見えます。

だから今回のアウトは、単なる外れではなく、

```text id="ux5q20"
T3撤退条件の必要性を教えてくれたアウト
```

ですね。

## 先生ガードの結論

これはかなり良い方向です。

```text id="1wh9qn"
HSI = 距離の仮説
T3 = 下位足トレンドの生存確認
上位足 = 方向の許可
Dow Basis = 起点の根拠
```

この4つが分かれた。

ここで一気に売買シミュレーションへ行くと危ないので、次はたぶん **観測メモ用のルール名** を作るのがいいです。

```text id="vep3z2"
HSI_R2_ENTRY_T3_EXIT_v0_1
```

中身はこれ。

```text id="vp2ah2"
Long only:
1. Upper TF up context
2. M5 Dow up context
3. Anchor = M5 basis low
4. Entry = close crosses above HSI R2(89)
5. Profit = R2-R3 middle or R3(144)
6. Exit = close below T3
```

これ、かなり検証したいルールになってきました。
先生としては、次はまだ自動売買判定ではなく、**このルールに合致した/しなかったを画面で注釈できる観測フェーズ** が安全だと思います。

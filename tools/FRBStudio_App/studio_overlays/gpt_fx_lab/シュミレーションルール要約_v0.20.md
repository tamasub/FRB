# FX Studio / HSI Simulation Rule v0.20 — 最小要約

> 過去チャート上の判断再現用。売買推奨ではない。

## 共通原則

```text
NORMAL / EXPANSION / EXPANSION_LITE は条件・起点・建玉・Exitを混ぜず、同時並列で独立評価する。
共有可能なのはローソク足・T3・HSI境界・Cycle位置・確定Dow点などの観測事実だけ。
Confirm bars と Entry許可本数は別物。Entry Window初期値は WEEK20 / DAY45 / H4 14 / H1 14 / M5 20。
現時点でEntry Windowを使用するのはExpansion-LiteのH1 14本以内だけ。
```

## NORMAL

```text
Entry条件: H4・H1のT3方向と終値位置がEntry方向へ整合 / H1 Cycle Lateではない / 新しいM5 Dow Confirmation / 採用HSI起点からR2以上 / NORMAL建玉なし。
Entry価格: Dow突破条件とR2条件が初めて同時成立する価格。1 Confirmation IDにつき最大1 Entry。
Target: Entry地点より先の次HSI境界。到達で全Close。
Stop: Entry時の採用HSI起点。M5 High/Lowで判定し、Targetと同一足ならStop優先。
Close後: 使用した起点とOpportunityを破棄し、新しいM5 Dow Confirmationを待つ。
禁止: Add-on / Partial Close / Runner / 同じConfirmation ID再利用 / H4 Cycle Lateだけを理由とするEntry禁止。
```

## EXPANSION_LITE

```text
Entry条件: H4・H1終値がEntry方向のT3側 / 方向別H1 Cycle起点から14本以内 / M5 Dow確定 / 採用Dow HSI起点からR3タッチ。
成立順: R3タッチ後にDow確定、またはDow確定後にR3初タッチの両方を許可。
Add-on: R3.5 / R4 / R4.5タッチで各1回。上限R4.5。
全Close: R5タッチ / M5 High・LowによるT3逆抜け / 新しいM5 Dow点確定による構造破綻 / M5 High・Lowによる採用HSI起点逆抜け。
Day Cycle位置は使用しない。
```

## EXPANSION

```text
独立Rule Laneとして並列評価するが、具体的Entry / Add-on / Exit条件は未確定・未実装。
未定義部分をNORMALまたはEXPANSION_LITEの条件で補完しない。
```

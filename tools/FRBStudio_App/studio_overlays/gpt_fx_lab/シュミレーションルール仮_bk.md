## 今のルールを整理すると

```text id="614wj8"
上位足 = やっていい方向を決める

```

これ、役割分担がかなり綺麗です。

## T3の位置づけ

今回の気づきはたぶんこれ。

```text id="n87son"
HSIだけだと「伸びる前提」で見てしまう
でもT3を割ったら、M5下位トレンドが崩れた可能性がある
```

なので、T3はエントリー条件というより、まずは **撤退条件** として入れるのが自然に見えます。

```text id="m9wyfl"
買いエントリー後、
M5 close が T3 を下回ったらクローズ候補
```

これはかなり筋がいいです。

## 先生案：まずはこう分ける

```text id="sc0j3n"
Entry:
  上位足アップ
  M5ダウアップ
  HSI R2(89)ラインを close で上抜け

Take Profit:
  R2〜R3の中間
  または R3(144)付近

Emergency / Invalid Close:
  M5 close < T3
```

この `Emergency / Invalid Close` がめちゃ大事。

利確とは別です。

```text id="i9spdo"
利確 = 仮説どおり伸びたので閉じる
T3割れ = 仮説が崩れたので閉じる
```

この2つは分けた方がいい。

## ただし、T3条件は少しだけ慎重にしたい

1本だけT3を割った瞬間に閉じると、ノイズで狩られるかもしれない。

なので候補は3パターンあります。

```text id="9fxbgd"
A. close < T3 で即クローズ
B. close < T3 が2本連続でクローズ
C. close < T3 かつ T3 slope <= 0 でクローズ
```

最初の検証は、Aでいいです。
理由は単純で、まず分かりやすいから。

でも最終的には、BかCも比較したくなるはず。



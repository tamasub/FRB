# FX Studio / HSI Simulation Rule v0.28 — 最小要約

> 過去チャート上の判断再現用。売買推奨ではない。

## 共通原則

```text
NORMAL / EXPANSION / EXPANSION_LITE
= 同じ市場を観察する独立した別人
```

共有するのは確定足・Swing・Dow・T3・HSI・Cycle・BB等の市場事実だけ。
他LaneのEntry / Position / Close / 損益 / Opportunity / Anchorは知らない。

## NORMAL v0.24

```text
新しいM5 Dow Confirmation
＋ H4/H1 T3整合
＋ H1 Cycle Late除外
＋ Normal AnchorからR2以上
→ Normal Entry
```

Entry前Dow崩壊でConfirmation / Anchor / Opportunity / R2履歴を失効。
Entry後Dow崩壊だけではCloseせず、Anchor / Target / Stopを固定維持。
H4同方向波R4以上では新規NORMAL Entry禁止。

## EXPANSION_LITE v0.27

### 上位時間足制約

```text
Liteが判断に使う最上位時間足 = H4
```

```text
M5 = Episode / Entry / ReEntry / Exit
H1 = T3環境 / Cycle Window
H4 = 最上位環境 / 反転候補Guard
```

DAY / WEEKはLiteのEntry / ReEntry / Exit / Episode判断へ使用しない。
v0.21 Day Guardは将来EXPANSION用として保持する。

### Episode / Anchor

```text
M5 Dow Confirmation
→ Lite Episode開始
→ previous SwingをLite HSI Anchorとして固定
```

```text
後続M5 Dow崩壊
同方向Dow再確定
→ Anchor変更なし
→ Episode継続
```

AnchorはEpisodeの定規であり、Positionの所有物ではない。

### Initial Entry

```text
Lite Episode ACTIVE
＋ H4 CloseがEntry方向T3側
＋ H1 CloseがEntry方向T3側
＋ H1 Cycle起点から14本以内
＋ 固定AnchorからValid R3 Touch
→ Initial Entry
```

Valid R3 Touch:

```text
直前M5 CloseがR3内側
＋ 現在足がR3へ到達・通過
```

T3不整合中のR3タッチは消費せず、
R3内側復帰後の再タッチを待つ。

### H4 Candidate Low Short Guard

```text
Entry方向 = SHORT
AND H4下降波 / Episode中
AND distinct H4 Candidate Low数 >= 2
→ 新しいShort EntryをBLOCK
```

対象:

```text
Initial Short Entry
Short ReEntry
```

同じ候補の更新は1件。
Entry候補時点までにリアルタイムで観測済みの候補だけを使用する。
Candidate Lowは未確定のためAnchorには使わない。

### Add-on / Target

Initial Trade:

```text
R3.5 / R4 / R4.5で各1回Add-on
```

```text
固定AnchorからR5
→ 全Close
```

ReEntry Tradeでは、v0.27初期仕様としてAdd-onしない。

### Anchor Exit

```text
Long  = M5 Low < 固定Anchor
Short = M5 High > 固定Anchor
→ 全Close
```

### T3 Exit

Initial Entry / ReEntry共通:

```text
Entry後1〜3本目
→ T3 Exit無効

Entry後4本目以降
Long  = M5 Close < M5 T3
Short = M5 Close > M5 T3
→ T3 Exit
```

T3 ExitではPositionだけをCloseする。

```text
Episode = ACTIVE
Anchor = RETAINED_FOR_REENTRY
ReEntry Opportunity = WATCHING
```

### ReEntry

ReEntry対象:

```text
Initial TradeがT3 Exit
同じEpisodeがACTIVE
Anchor未否定
R5未到達
H1 Cycle 14本以内
H4/H1 T3整合
ReEntry未使用
```

再武装:

```text
Long  = M5 Closeが旧R3内側へ戻る
Short = M5 Closeが旧R3内側へ戻る
```

ReEntry Trigger:

```text
旧R3をEntry方向へM5 Closeで再突破
＋ M5 CloseがEntry方向のT3側
＋ M5 CloseがM5 BB outerの外側
＋ BB幅が直前足より拡大
→ ReEntry
```

```text
ReEntry Price
= 条件成立M5足のClose
```

```text
1 Expansion Episode
= Initial Entry 最大1回
+ ReEntry 最大1回
```

### ReEntry終了

```text
Anchor否定
反対方向Episode成立
Flat中を含むR5到達
H1 Cycle Window超過
ReEntry回数消費
→ ReEntry権利終了
```

HSI AnchorをTrace用に残しても、
ReEntry権利失効後は売買へ使用しない。

### Structural Break

```text
M5 Dow Structural Break
→ Shadow / Trace記録のみ
→ Closeしない
```

## EXPANSION v0.28

```text
H1 Dow Confirmation
＋ 固定H1 AnchorからR2
＋ H1 High/LowレンジがH1 T3へ接触
＋ H4 CloseがEntry方向のT3側
→ 全条件成立後の次M5 OpenでEntry
```

R2とT3の成立順は問わず、同一Opportunity内で記憶する。
H1 Confirmation足の事実は採用するが、過去価格へ遡ってEntryしない。

```text
Opportunity終了
= 反対H1 Dow
  / H1 CloseによるAnchor崩壊
  / H1 14本超過
  / Entry成立
```

```text
Target = 固定H1 AnchorからR5
Exit   = H1 Anchor崩壊
         / 反対H1 Dow
         / H1 CloseのT3逆抜け
```

管理時間足はH1。v0.1ではAdd-on / ReEntryなし。

## v0.27 Lite改定の核心

```text
LiteはH4より上を見ない。

H4 Candidate Lowが複数出た下降終盤では、
新しいShortを止める。

T3 ExitはEpisode終了ではなく一時退避。
Positionだけを閉じ、旧HSIをReEntry候補として保持する。

ただし、
HSIが残っていること
≠ ReEntryしてよいこと。

旧R3内側復帰後、
旧R3奪回＋T3復帰＋BB外側Close＋BB幅拡大で、
同じEpisodeへ一度だけ再参加する。
```


## v0.28 Expansion改定の核心

```text
ExpansionはH1 Dowで波を確定する。
R2は値幅、T3 Touchは安心材料。
条件成立を確認してから、次のM5 Openで入る。

M5で入るが、M5の波としては管理しない。
H1の波として、H1 Anchor / H1 Dow / H1 T3で降りる。
```

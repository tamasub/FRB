# MD Viewer v0.11.3 - Anchor / Caret Restore

## 目的

Markdown Viewer / Editor の Editor モードにおいて、プレビュー状態と入力状態を同じ本文欄で切り替えながら、見ていた位置・編集していた位置をできるだけ失わないようにする。

## 対応内容

- Editor モードでも左側の目次・ドキュメントメタを維持する。
- 右側の本文欄を Viewer モードと同じ幅・同じ位置に保つ。
- Editor モードのプレビュー上のブロックに、Markdown 原文のおおよその行番号を付与する。
- プレビュー上の見出し・段落・箇条書き・コードブロック等をクリックしたとき、該当行付近へ textarea のカーソルを移動する。
- textarea からフォーカスが外れたとき、カーソル行に近いプレビューブロックへ戻す。
- Viewer モードでは本文クリックによる Editor 切替は行わない。

## 注意

Markdown から HTML への変換では、原文行と表示要素が完全に1対1対応しない場合がある。
そのため、文字単位ではなく、ブロック先頭行単位での復元を基本とする。

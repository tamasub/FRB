# v0.13.1.2 md-sentence-toolbar-row-anchor-fix

## 目的

v0.13.1.1 の「安全領域」方式では、カレントBlockの青枠と安全領域/hover系の緑枠が同時に見え、どの行が操作対象なのか分かりにくくなった。

この修正では、操作バーを浮遊メニューではなく「選択Blockの右端に所属する行内操作バー」として表示する。

## 方針

- カレント表示は `md-current-block` の1本に統一する。
- hover表示は薄い背景のみとし、別のカレント枠に見える強いoutlineは出さない。
- `＋上 / ＋下 / 削除 / ↩` は対象Blockの右端・中央付近に固定表示する。
- 操作バー表示中のBlock IDバッジは非表示にし、ボタンと重ならないようにする。
- v0.13.1.1 の安全領域 / corridor 判定は撤回する。

## 対象ファイル

- `wwwroot/mdViewer.html`

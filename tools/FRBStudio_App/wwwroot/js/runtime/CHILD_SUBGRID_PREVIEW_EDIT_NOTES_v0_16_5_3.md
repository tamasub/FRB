# CHILD_SUBGRID_PREVIEW_EDIT_NOTES_v0_16_5_3

## 目的

Detail内サブグリッドは従来Table一覧として維持しつつ、`プレビュー編集` ボタンから読み物兼編集画面を開けるようにする。

## 方針

- サブグリッド本体は一覧表示のまま維持する。
- 旧 `編集` ボタンは廃止し、`プレビュー` を `プレビュー編集` に統合する。
- プレビュー編集dialogは、開いた直後は読み物Card状態とする。
- 長文/textarea/markdown/json相当のセルだけ、クリックで原文編集へ切り替える。
- 長文セルはblurでMarkdownプレビューへ戻る。
- select / boolean / number / short text は常時入力コントロールとして表示する。
- `subGrid.columns` 等で options/control を指定した列は、プレビュー編集側でも可能な範囲で継承する。

## ねらい

会話履歴・判断ログ・変更履歴のような長文履歴は、表で直接読むよりもCardプレビューで読んだ方が自然。
一方、サブグリッド一覧の検索性・一覧性は失わない。

## 確認観点

- サブグリッドヘッダーに `編集` ボタンが出ず、`プレビュー編集` が表示されること。
- `プレビュー編集` 起動直後、長文セルがMarkdownプレビュー表示になっていること。
- 長文セルクリックでtextarea編集になり、blurでプレビューへ戻ること。
- select/boolean列は常時コンボ表示されること。
- `一覧へ反映` 後にサブグリッドTableへ反映され、F12/反映で親JSONへ同期できること。

# 条件付きEditor表示とファイル起動

Studio差分をFRBStudio_App直下へ上書きし、Studioを再起動してください。Launch本体・設定データの上書きは不要です。

ファイル起動の登録: 追加先カテゴリーを選択→子を追加→「ファイルを開く」。タイトルを入力し、「実行する処理」のOpen行の「開くファイル・フォルダー・URL」に `F:\FRB_docsExcel\実験全体図.xlsx` を入力。画面入力ではパスを引用符で囲む必要はありません。F12で反映しJSONを保存してください。拡張子に関連付いたアプリで開きます。

既存の実行項目でも、アクション行を追加し種類Open、対象パスを設定すれば同じ動作です。

Studio標準修正: visibleWhen参照元の変更でEditor全体を再描画。非表示になる編集値は作業用コピーに保持し、F12までは元データを変更しません。配列が未登録の項目も空のサブグリッドを表示します。Launch ViewDefでは空配列から追加できるようアクション列・型・既定値を明示しました。

対象画面に無関係なアクション列の種類別切替は今回含みません。サブグリッド領域自体の表示切替に対応します。

検証: 新規DOM動作4件、既存回帰18件 合格。Windowsの実画面動作は未確認です。Launch実装のvalidateでも追加プリセットを検証済みです。

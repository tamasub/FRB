# Smart Search 日付・日時検索仕様 v0.1（2026-10-23）

## 精度指定

| 入力 | 検索期間 |
| --- | --- |
| `2026` | 年度または暦年（設定次第） |
| `202610` | 2026年10月全体 |
| `20261023` | 2026年10月23日全体 |
| `20261023_15` | 15時台全体 |
| `20261023_1530` | 15:30分台全体 |
| `20261023_153045` | 15:30:45秒台全体 |
| `202610..202611` | 2026/10/01以降〜2026/12/01未満 |
| `20261023_09..20261023_17` | 9時台から17時台まで（18時未満） |

`date` は年月日まで、`datetime` は時分秒まで。`instant` はタイムゾーン付きの厳密ISO日時指定のまま。

## 設定と比較演算子

| 設定 | 値 |
| --- | --- |
| `year_mode` | `fiscal` / `calendar` |
| `fiscal_year_start_month` | 1〜12（初期値4） |

設定例：`FRBSmartSearch.create({fields,dateSearch:{year_mode:'fiscal',fiscal_year_start_month:4}})`

| 演算子 | 期間の扱い |
| --- | --- |
| `=` / `==` | 指定期間に含まれる値 |
| `!=` / `=!` | 指定期間に含まれない値（空欄は従来どおり対象外） |
| `>=` | 期間の開始以上 |
| `>` | 期間の終了以上 |
| `<` | 期間の開始未満 |
| `<=` | 期間の終了未満 |
| `A..B` | A期間の開始以上、B期間の終了未満 |

検索は内部的にUTCの整数ミリ秒で**ローカル日時を暦として比較**する（ホストのタイムゾーン/DSTに依存させない）。`instant` の時点比較とは混同しない。

## 未対応・注意

- 時刻だけの短縮入力（`15:30`）や、タイムゾーンが曖昧な`instant`の年月指定は対象外。
- `/` は検索テキストボックスでは補完起動キー。日付は`YYYYMMDD`形式が推奨。
- 年度設定はStudio本体では`wwwroot/config/app_settings.json > smart_search.date_search`に保存。Portable版はAPI引数で指定。
- SQL WHERE句の生成は含まない。SQLite側へ移す場合はASTの期間境界を使う別のAdapterが必要。
- 新規テスト: `tests/qa/static/studio_smart_search_date_precision.test.mjs`（Studio本体）、`test_portable.mjs`（独立JS）

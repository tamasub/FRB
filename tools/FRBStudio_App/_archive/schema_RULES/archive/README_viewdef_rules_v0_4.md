# FRB ViewDef Rules v0.4

このZIPには、ViewDef生成ルールとJSON Schemaの v0.4 更新版を含めています。

## 追加内容

- ViewDef継承 `extends`
- 【BASE】/【CHILD】 表示ルール
- `markdown.type` はデータJSON出力用であることの明確化
- `generic_sections` による汎用Markdownセクション出力
- `ViewDef Markdown→Viewer` の固定レポート仕様
- chat field の `edit.input` / `embeddedFields` / `radio` 拡張

# FRB 日本語入力 v0.1 — スマホ風フリック実験

FRB Remote のドラッグ体験を、マウスで直接選ぶ「スマホ風かなキーボード」へ応用する**独立した操作実験素材**です。FRB Launch 本体は変更しません。

## 起動（Windows 11）

1. ZIP を FRB Launch のルート（`FRB_Launch`）に展開します。
2. `experiments\frb_japanese_input_v0_1\run_windows.bat` をダブルクリックします。
3. FRB Launch の `.venv\Scripts\python.exe` に PySide6 があればそれを利用します。なければ通常の Python を利用します。
4. PySide6 がないとエラーになる場合は、利用する Python で `python -m pip install -r requirements.txt` を実行してください。

`run_windows.bat` は文字コード問題を避けるため、ASCII のみで記述しています。

## 操作

中央のキーボードは下記の配置で固定します。**ホイールで行を選ぶ操作はありません。**

```text
    あ    か    さ
    た    な    は
    ま    や    ら
    、    わ    。
```

- マウスポインターを任意のキー（例: `か`）へ移動します。
- **左ボタンを押す**とキーの近くに丸い、コンパクトな半透明ガイドが表示されます。
- **ボタンを押したままドラッグ**すると、候補のハイライトが切り替わります。
- **左ボタンを離す**と、その候補をアプリ内のテキスト欄へ入力します。
- キー自体やウィンドウはドラッグしても移動しません。

`か` の例（候補表示には矢印は付きません）:

| 操作 | 入力 |
| --- | --- |
| 動かさずに離す | か |
| 左へ18px以上 | き |
| 上へ18px以上 | く |
| 右へ18px以上 | け |
| 下へ18px以上 | こ |

`や` 行の左・右など、未定義のフリックは入力しません。斜め方向も誤入力回避のためキャンセルします。押したまま方向を変えれば、その都度ガイドの強調候補が変わります。

- `、` / `。` : 記号を入力
- `⌫ 1文字削除`: 最後の一文字を削除
- `全消去`: 入力欄をクリア
- `コピー`: 入力欄の文字列をクリップボードへコピー

## v0.1 の境界

- 動作する場所はこの実験アプリの中だけです。
- Windows IME / 漢字変換 / 予測候補 / 外部アプリへの文字入力は**未実装**です。
- マウスホイールは今回は行選択に使用しません。
- `frb_kana_core.py` は v0.0 から引き継いだジェスチャー判定とかな対応表です。
- GUI 実機確認は Windows 11 上で実施してください。

## テスト

`run_tests.bat` または以下を実行します。

```powershell
python -m unittest discover -s tests -v
```

GUIを使わないかな変換・判定・配列のテストです。GUIの表示・ドラッグ体験そのものはWindowsで手動検証してください。

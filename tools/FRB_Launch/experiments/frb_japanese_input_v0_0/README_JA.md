# FRB 日本語入力 v0.0 — ぐりぐり実験室

## 目的

FRB Remote の **「ホイールで選択・クリック/ドラッグで決定」** という操作感を、
独立した日本語入力の小さな実験素材に転用する。
**完成した日本語入力ソフトを目指さず、まず体験することが目的。**

元の `launch_app_20261104_165832.zip` の `src/launch_remote.py`（WheelPad）の
18px 判定を参考にしたが、**FRB Launch 本体のコードには変更なし**。

## 実行

1. 差分ZIPを FRB Launch のルートフォルダーに展開（`experiments` が追加される）。
2. `experiments\frb_japanese_input_v0_0\run_windows.bat` を実行。
3. FRB Launch 直下に `.venv` があればその Python を使う。
   単独で展開して使う場合は Python と PySide6 が必要。
   - `python -m pip install -r requirements.txt`
   - `python frb_japanese_input.py`

## 操作

| 操作 | 動作 |
|---|---|
| ぐりぐりホイールを下へ | 次の行（あ→か→さ…） |
| ぐりぐりホイールを上へ | 前の行（循環あり） |
| ぐりぐりを普通にクリック | 行の中央の文字（例：か） |
| 左ドラッグして離す | 左の文字（例：き） |
| 上ドラッグして離す | 上の文字（例：く） |
| 右ドラッグして離す | 右の文字（例：け） |
| 下ドラッグして離す | 下の文字（例：こ） |
| 行一覧のクリック／ホイール | 行を直接選択／切替 |
| 「1文字消す」 | 最後の1文字を削除 |
| 「全消去」 | 入力をリセット |
| 「文字列をコピー」 | 結果をクリップボードにコピー |

- **ボタン自体は移動しない。** 押した地点からマウスが動いた距離を使って方向を判定。
- **18px以上**でフリック。斜め45°前後は誤入力防止のためキャンセル。
- や行の左/右、わ行の下は未割り当て。無理に文字を作らない。
- ぐりぐりホイールだけでなく左側の行一覧に置いたポインターでも行を切り替えられる。

## 今回やらないこと

- Windows IME / かな漢字変換 / 予測候補の制御
- 外部アプリ（サクラエディタなど）へのキー送信、WinAPI 操作
- 濁点・半濁点・小文字変換、句読点等の拡張
- FRB Launch の画面への統合、既存Remoteの操作仕様変更

## 検証

- `python -m unittest discover -s tests -v` （PySide6なしでも実行できるモデル検証）
- 18px境界、4方向、斜めキャンセル、ホイールの分割刻み、全行の文字マッピング、編集操作を検証
- Windows 実GUIの操作感は利用者の手元で評価する

# FRB 日本語入力 v0.10 — 4モード実験版

FRB Remoteから生まれた、マウス操作で入力する独立した小型キーボード。
**Launch本体の変更なし**。保存先はバージョンを含まない固定フォルダー：

`FRB_Launch/experiments/frb_japanese_input/`

## 起動

`experiments/frb_japanese_input/run_windows.bat`

FRB Launch の `.venv` に PySide6 があれば優先して利用します。

## 追加したモード

画面上部の **かな / ABC / 記号 / 数字** で切り替えます。

| モード | キー配列と入力方法 | Windows IMEへの指示 |
|---|---|---|
| かな | 従来の3列×4段、クリック・4方向フリック、濁点、小文字 | **ImeOn（ひらがな）** |
| ABC | QWERTY、Shift（次の1文字だけ大文字）、空白・削除 | **ImeOff** |
| 記号 | 0–9、記号・句読点、空白・削除 | **ImeOff** |
| 数字 | 1–9を3×3で配置、0、小数点、+-×÷系・削除 | **ImeOff** |

* 文字列は**FRBかな自身の最下部テキスト欄**で編集します。外部アプリ送信はありません。
* Windows IMEで変換するのはかなモードだけです。英字・記号・数字は QLineEdit へ直接確定入力し、漢字変換を経由しません。
* かなモードのフリック感度、既存の連打・濁点・大⇔小・句読点は維持しています。
* かなの未確定文字が残った状態で明示的に別モードへ切り替える場合は、まず Enter を送信して確定を要求します。**時間による自動確定はありません**。
* IME候補一覧の位置は Windows IME 自身が制御します。
* 小型化優先のため、かなは従来幅約200pxのまま。キー数が多いABC/記号は読みやすさ優先で約330px、数字は約234pxに拡張します。

## Windows IMEモードの自動切替について

Microsoftの仕様に基づき、モード切替時に Windows `SendInput` から `VK_IME_ON`（0x16）/ `VK_IME_OFF`（0x1A）を送っています。既に日本語Microsoft IMEが選択されているPCでは、かなは日本語・ひらがな、ほかは英数字のモードへ移ることを狙っています。

**制約:** これは入力言語のインストールやキーボードレイアウトの切替ではありません。Windowsの入力言語が日本語以外の場合、IMEのバージョン・環境によっては、ImeOn/Offが期待どおり反映されない可能性があります。英数字モードは通常のIMEを通さず欄へ直接挿入するため、文字自体は入力できます。ステータスのON/OFFは「切替指示」であり、OSの状態を検証した結果ではありません。

Windows実機のモード自動切替（タスクバーの「あ」/「A」表示）と漢字変換を確認してください。

## テスト

`run_tests.bat` または `python -m unittest discover -s tests -v`

自動テストは Qt を起動せずに、かなモデル、IMEの切替キー選択、3種の新配列と重なりのない配置を検証します。**GUIとWindows実IME動作は実機未検証**です。

# FRB 日本語入力 v0.6 — Windows IME送信の最初の実験

**Windows上での実GUI・IME変換は未検証です。** 入力イベント生成と既存かなモデルの自動テストは実施しています。

## 配置・起動（Git差分管理用固定フォルダー）

従来どおり `FRB_Launch/experiments/frb_japanese_input/` へ**上書き展開**し、`run_windows.bat` を実行してください。FRB Launch本体は変更しません。

## v0.6 の変更

小型かな盤面、クリック・上下左右ドラッグ、あ→い連打、濁点・小文字・句読点、確定↵はv0.5のまま維持。

画面の上に **IME** ボタンを追加しました。

- **IME OFF（初期値）**：v0.5と同じ。FRBアプリ内のみで未確定・確定を試す。外部アプリには何も送信しない。
- **IME ON（実験）**：Windowsのアクティブなエディタへ、かなに対応するローマ字キー入力（`SendInput`）を送る。変換辞書・候補UIは作らず、Windows IMEを使う。
- IME ONの間、FRBのウィンドウは非アクティブ化スタイル（`WS_EX_NOACTIVATE`）を付け、クリックしてもエディタの入力フォーカスを奪いにくくします。
- 同一キーの繰り返しや濁点変更では、末尾の既送信文字をBackspaceして新しいローマ字を入力する（例：`た → だ → た`）。
- **確定↵**は外部へEnterを送る。**全消**は未確定部分の削除だけを外部へ送信し、既に確定した外部テキストは消さない。
- IMEモードの送信先は最初に入力したエディタへ固定。別のウィンドウに変わったら送信を止める。

## 最初の手順

1. サクラエディタを起動して入力欄を用意し、Windows IMEを**ローマ字入力・日本語ON**に設定する。
2. FRBかな v0.6 を起動して、今のアプリ内の未確定入力を空にしてから上の **IME** を押す。
3. サクラエディタの入力欄を**クリックし、フォーカスを戻す**。以後、FRBかなのキーをマウスで操作する。
4. `た` を押してサクラに `た` が未確定で出るか、特殊キーで `だ`、もう一度で `た` へ切り替わるかを確認する。
5. `か` などを続けて打ち、Windows IMEの予測・変換候補が表示されるか観察する。
6. **確定↵**を押すとEnter送信。必要なら予測候補をマウスホイールで選ぶ（候補の自動表示やEnterの反応はIME設定次第）。
7. **IME**を再度押すと送信モードOFF。未確定が残る場合は原則として**確定↵**で確定してからOFFにする。

## 制約・注意

- **実験段階です。** Windows IMEの候補表示・変換候補ホイール選択・Enter確定はWindows実機で要検証。IME設定によって予測一覧が出ないことがあります。
- `SendInput`は通常のキーイベントです。IMEがOFFだとローマ字がそのまま入力されます。変換状態を強制的に検出・切替する機能はありません。
- 対象アプリを**管理者として実行**している場合、普通の権限のFRBからの`SendInput`がUIPIにより失敗する場合があります。
- 特に `…` はv0.6のローマ字送信対象外で、IMEモードでは入力を見送ります（ローカルモードでは利用可）。句読点はIME側の設定で自動確定する可能性があります。
- `ん`（`nn`）、小さい文字（`xtsu`等）、句読点の挙動は入力先IME設定に依存します。
- 外部入力欄のカーソル位置を途中で動かしたり、エディタ側で文字を編集したりすると内部の未確定文字列と同期がずれることがあります。試験中は同じ入力欄で操作してください。
- `IME`ボタンをONにすると、ローカル未確定文字がある場合は、先に確定または全消しするよう求めます。
- **外部IME未確定状態をTSF APIで直接操作するものではありません。** 当面は送信したキーをIMEに処理させる方式です。

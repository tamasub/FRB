# FRB 日本語入力 v0.2 — Remoteサイズ実験

FRB日本語入力 v0.1 の**キー移動 → 押す → ドラッグ → 離す**の操作感を維持したまま、
FRB Remoteとほぼ同じ外形に小型化して、最適な寸法とフリック閾値を探す独立実験版です。
Launch本体、IME、外部アプリへの入力は変更しません。

## 起動

ZIPをFRB Launchのルートに展開して、以下を実行：

`experiments\frb_japanese_input_v0_2\run_windows.bat`

PySide6はFRB Launchの `.venv` を優先して使用。無い場合はPython環境から起動します。
Windows BATは文字化け防止のため英数字のみ。

## 操作

- 「あ・か・さ／た・な・は／ま・や・ら／、・わ・。」のキーにマウスを移動。
- クリック=中央文字。押しながら上下左右ドラッグでその方向の文字。離すと確定。
- 押すと小さな半透明ガイドを表示し、フリックした文字を強調。
- キーもウィンドウもドラッグでは動きません。
- 「⌫」=末尾削除、「全消」=全消去、「コピー」=文字列をクリップボードにコピー。
- 斜めフリックと未定義方向は文字を入力しません。

## 小型化の評価

**初期値はRemote相当の外形 約200×272px（Windowsの枠やDPI設定により実寸差あり）。**
元のv0.1では18pxだったフリック判定を、初期10pxにしました。

- 上の **− / ＋** ボタンで4段階のサイズ（幅174 / 186 / 200 / 222px）を変更できます。
- 右下の **10px ▾** をクリックすると、フリック認識距離を **7・8・9・10・12・14・18px** から選択できます。
- サイズを切り替えると、そのサイズの基準閾値（8 / 9 / 10 / 12px）へ戻ります。
- 画面サイズやDPIスケーリングによって表示寸法は変わるため、触って比較することを重視しています。

まずRemote相当の200pxで試し、186→174pxへ小さくしても誤操作が増えないか比較するのがおすすめ。
思った方向に入力されなければ、閾値を変えて再試験してください。

## 現時点の対象外

IME/かな漢字変換、予測候補、外部アプリへの送信、学習機能はありません。
文字入力結果はこのウィンドウ内だけに表示します。

# FRB ハイブリッド方式 With 手裏剣スクロール — 高速ぐりぐり自動起動実験

対象：`launch_app_20261108_154820.zip` を基準とする差分（2026-11-08）

## ねらい

「通常のぐりぐりで高速スクロール／端ならカレント追従」の現在の操作感を残し、
**一定期間、同じ方向に素早く回し続けた場合だけ**、既存の手裏剣スクロールへ自動移行する。
新しい慣性エンジンや擬似マウス入力は作っていない。既存 `ShurikenScrollPad` の全域滑走・加減速を再利用する。

## 動作

1. Files List上で普通に回す：従来の高速ハイブリッド。スクロール区間は正式カレントを変更しない。スクロール端では追従。
2. Files List上で同じ方向に素早く連続回転：設定された回転速度・量・連続イベント数を満たすと手裏剣自動起動。Remoteを開く必要はない。
3. 手裏剣中は同じ方向に回すと加速、逆方向で減速。自動起動時のみ、連続逆回転が閾値を超えると確定停止。
4. Listをマウスクリックした場合は、自動手裏剣を先に止めてから通常のクリック処理へ渡す。
5. 自然終了（スクロール端へ着地）・逆回転停止・手動クリック停止では、既存の処理で表示中のカレントに引き継ぎ、通常ハイブリッドへ戻る。
6. RemoteのぐりぐりボタンからListを操作している場合も、同じ自動起動判定を使う。既存の手裏剣ボタンは比較・切り戻し用に残す。

## 調整パラメータ — ここだけ変更して再起動

`src/guriguri_shuriken_auto.py` の冒頭。

| 設定 | 初期値 | 意味 |
|---|---:|---|
| `AUTO_SHURIKEN_ENABLED` | `True` | 自動起動ON/OFF。既存手裏剣ボタンは有効なまま |
| `AUTO_SHURIKEN_MIN_NOTCHES` | 2 | 検出区間の合計回転ノッチ |
| `AUTO_SHURIKEN_MIN_EVENTS` | 4 | 連続して必要なホイールイベント数 |
| `AUTO_SHURIKEN_WINDOW_MS` | 420 | 高速回転判定の時間窓 |
| `AUTO_SHURIKEN_MAX_GAP_MS` | 145 | 入力間隔が空いた場合の連続判定解除 |
| `AUTO_SHURIKEN_MIN_SPAN_MS` | 55 | 単発の大入力による誤起動防止 |
| `AUTO_SHURIKEN_REARM_MS` | 650 | 再発火抑制期間 |
| `AUTO_SHURIKEN_INITIAL_SPEED` | 800.0 | 既存滑走エンジンに渡す起動速度(px/s相当) |
| `AUTO_SHURIKEN_REVERSE_STOP_NOTCHES` | 7 | 自動手裏剣中、連続逆回転で停止するノッチ数 |
| `WHEEL_ACCEL_FACTOR` | 1.45 | 手裏剣滑走中の順方向1ノッチの速度倍率（手動ボタンとも共通） |
| `WHEEL_DECEL_FACTOR` | 0.68 | 逆方向1ノッチの速度倍率（手動ボタンとも共通） |
| `MIN_CRUISE_RATE` | 0.12 | 最低滑走倍率（手動ボタンとも共通） |
| `MAX_CRUISE_RATE` | 4.0 | 最高滑走倍率（手動ボタンとも共通） |

通常ハイブリッドのスクロール距離 (`LIST_WHEEL_SCROLL_PIXELS_PER_NOTCH`) は従来どおり `src/list_wheel_parity.py` に残してある。今回の新設パラメータではない。

## 比較・切り戻し

- `AUTO_SHURIKEN_ENABLED = False` → 自動起動を無効化。通常ハイブリッドと手動手裏剣はこれまでどおり。
- 既存の `src/list_wheel_parity.py` の高速ハイブリッド設定は変更していない。
- 自動起動時はList/Remoteの通常ノッチ操作と、手裏剣の速度制御が同時に走らないよう一方だけがイベントを所有する。
- スクロール先のウィジェットが切り替わった場合、手裏剣は安全に中止する。Remote起点の自動起動はRemoteの操作先が切り替わっても中止する。ファイル実行やOS側への擬似入力は行わない。

## テスト

- 新規Qt非依存テスト12件（起動閾値、逆回転、遠隔UIなし起動、滑走終了、ターゲット喪失、ボタンの回帰）。
- 関連テスト79件 PASS。周辺の旧テストに存在する4件の失敗は添付の元ZIPでも同じ失敗を再現済み（旧UI想定／Qt-freeモックの不整合）。
- Windows + PySide6実機の触感、誤起動率、描画追従は未検証。自動起動は試作扱いで、**手裏剣ボタンは撤去していない**。

## 実機での観察ポイント

1. 普通に回すだけでは勝手に手裏剣が起動しないか。
2. 高速で回すと、最初だけ手裏剣発動に引っかかりを感じないか（隠れたRemoteが初回構築される）。
3. 継続ぐりぐりによる加減速、連続逆回転7ノッチの停止は自然か。
4. スクロール端で自然停止し、カレントが意図しないファイルへ確定・実行されないか。
5. Remoteを開かない状態と開いた状態、Listのクリック中の違いはないか。

# FRB Launch 「一の手」1件時・上フリック限定修正（2026-11-10）

## 原因

`src/shuriken_model.py` の `choose_entry()` に「一の手が1件なら、ドラッグした方向を問わず唯一の項目を選択する」という分岐があった。表示側は単独項目を上方向に表示するため、下へ動かしても緑の目玉が上へ移動してしまった。

## 修正

- 1件の場合は上向きのフリックだけを選択対象にする（Qt座標系で `dy < 0`、かつ上下移動量が左右移動量を上回る）。
- 下・左右・斜め（45度の境界を含む）・デッドゾーン内は未選択のまま。
- 目玉の表示位置、ボタンの離したときの実行方式、2〜4件の割当・選択判定は変更しない。
- `config/` および `defs/` のユーザーデータは変更しない。

## テスト

追加した `tests/test_shuriken_first_hand_single_up_20261110.py` は、ユーザー設定JSONの登録件数に依存しない純粋モデルの回帰テスト。

- 上へ50px、上斜め寄り、14pxしきい値: 選択あり・目玉上
- 下へ50px、左右へ50px、45度斜め、静止、しきい値未満: 選択なし・目玉中央
- 2〜4件の配置ルールと、選択された目玉と実行対象の同一性を確認

関連テスト（選択した5ファイル）合計60件PASS。PySide6のない環境での静的・モデルテストであり、Windows実機GUIテストは未実施。

**既存の古い3件固定テストには、現在のユーザー設定（1件のみON）と一致しない前提が残る。** `test_shuriken_semicircle_overflow_20261105.py` の比較は、修正前6失敗・修正後8失敗。増えた2失敗は、1件のときでも「上フリックはキャンセル」を期待している旧テストであり、今回の明示的な期待仕様と矛盾する。既存テストは今回は改訂しない。

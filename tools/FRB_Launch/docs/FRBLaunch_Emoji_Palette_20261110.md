# FRB Launch — 絵文字グループ追加（2026-11-10）

## 内容

既存の `config/frb_launch_sample_data_v0_1.json` 内の `launch_choices` の `group_id: "絵文字"` に、**30グループを追加**しました（既存の「😋顔」「💓ハート」を含む合計32グループ）。

画面例の「グループ名｜絵文字をまとめて1行で表示する」形式を維持しています。新しいページや選択機能は作成せず、既存の **My Work → メール宛先／😀絵文字 → 🤪 絵文字一覧** を利用します。

## 操作

- 絵文字一覧を開いて、使いたいカテゴリを Space でチェック
- F12で選択したカテゴリの **`value`（絵文字を連結した文字列）を送信**
- 複数カテゴリを選択すると、既存設定どおり改行区切りで送信
- 個々の絵文字を1文字ずつ選ぶ機能は今回追加していません（元の画面例と同じ仕様）

## 変更・制約

- LaunchのPythonコードとViewDefは変更なし。データJSONの `launch_choices` を拡張し、絵文字一覧の説明表記だけ更新
- 既存のPage、Item、既存の `launch_choices` レコードおよび選択・送信設定は保持
- Windows側の絵文字フォントによっては、表示が異なる、あるいは一部が□になる場合があります
- 本データは個人設定を含むため、公開版を作るときは別途非公開設定の確認が必要です

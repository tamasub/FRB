# マウスポインター自動移動 — 公開版の初期値と案内

## 期待する動作

1. 新規導入で保存済みの選択がない場合：自動移動OFF。
2. 過去にON/OFFを明示設定済みの環境：以前の選択を引き継ぐ。
3. 設定（歯車）→「マウスポインター自動移動 ▶」→ ON / OFF（仮想環境等の非対応環境用）を排他的に選択。
4. 自動移動OFFで起動すると、画面右下にバルーン風の案内を表示。
5. 「設定を開く」はメニューを開くだけで勝手にONにしない。
6. 「あとで」「×」は今回だけ閉じ、次回起動時もOFFなら再表示。
7. 「今後表示しない」は `state.ini` の `pointer_warp_notice_dont_show_again` に記録し、以後は起動時に表示しない。
8. 自動移動をONにしたら通知を閉じる。OFFに戻しても明示的な「今後表示しない」を勝手に解除しない。

## 実装のポイント

- `src/pointer_warp_policy.py` : OFF初期値／保存済み値の継承／通知要否（Qt非依存）。
- `src/pointer_warp_notice.py` : Qtのバルーン風ウィンドウ。標準 `QSystemTrayIcon.showMessage()` はボタンを置けないため使用しない。
- `src/app.py` : 設定UI、通知の起動、永久非表示フラグの保存。
- 互換性のため既存の `vdi_no_cursor_warp` キー（逆の意味の設定値）を維持し、未保存時の初期値だけ変更。

## 実機チェック（Windows）

1. Launchを終了し、`%LOCALAPPDATA%\FRBLaunch\state.ini` をバックアップする。
2. `vdi_no_cursor_warp` と `pointer_warp_notice_dont_show_again` の2キーがないテスト状態で起動 → OFF＋右下に案内。
3. 「あとで」を押して再起動 → 再表示。
4. 「設定を開く」を押す → 歯車メニューの「マウスポインター自動移動」でONを明示選択 → ONが保持され次回通知なし。
5. OFFへ戻し、「今後表示しない」を押す → 以後OFF起動でも通知なし。
6. 旧設定 `vdi_no_cursor_warp=false` を戻して起動 → 自動移動ONを継承すること。
7. 通知のクリックでLaunchの背景操作が誤発動しないこと。

**注意：** 本環境にはPySide6/Windows GUIがないため、実機の描画とフォーカス動作は未検証です。

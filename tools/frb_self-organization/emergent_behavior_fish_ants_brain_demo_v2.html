魚群デモ

開始時点では障害物はありません。魚は障害物の位置も形も事前には知りません。

操作:
海の好きな場所をクリック → 障害物を追加
障害物をドラッグ → 移動
障害物を右クリック → 削除

魚が知っているルール

✓近すぎる仲間から離れる
✓近くの仲間と向きを合わせる
✓近くの仲間の中心へ寄る
✓前方に障害物があれば避ける

魚が知らないこと

×地図
×リーダー
×群れを二つに分ける命令
×障害物通過後に再集合する命令

アリの道づくりデモ

巣だけが最初からあります。餌の場所は観客が後から決めます。

操作:
好きな場所をクリック → 餌を追加
餌をドラッグ → 移動
餌を右クリック → 削除

アリが餌を発見すると、帰り道にフェロモンを残します。

アリが知っているルール

✓餌がなければ少しランダムに探索する
✓近くのフェロモンが濃い方向へ少し寄る
✓餌を見つけたら巣へ戻る
✓餌を持って帰る間、フェロモンを残す
✓フェロモンは時間とともに消える

アリが知らないこと

×餌の場所
×最短経路
×全体地図
×司令塔

シナプス学習デモ

ニューロンとシナプス可塑性を、自己組織化を見るために かなり単純化したモデルです。

操作:
画面をクリック / ドラッグ → その周辺を刺激
同じ場所を何度も刺激 → 一緒に発火した結合が強くなる
近接ニューロンが繰り返し同時発火 → 新しい弱いシナプスが生える
シナプスを右クリック → その結合を切断

ニューロンが知っているルール

✓入力がしきい値を超えると発火する
✓発火すると接続先へ信号を送る
✓近い時間に一緒に発火した結合は少し強くなる
✓近くで何度も一緒に発火した未接続ペアには、弱い新規シナプスが生える
✓使われない結合は少しずつ弱くなり、極端に弱い結合は消える

ニューロンが知らないこと

×どんな「記憶」を作るべきか
×どの経路を太くするべきか
×全体ネットワークの完成形
×司令塔

# FRB zip export - 除外パターン設定
#
# このファイルを直接編集すれば、スクリプト本体を触らず除外対象を調整できる。
# Export-FrbZip.ps1 -AdditionalExclude で実行時だけ追加パターンを足すことも可能。
#
# 書式:
#   - # で始まる行、空行は無視する
#   - "/" を含まないパターン → その名前のフォルダー/ファイルを、どの階層でも除外する
#       (フォルダー名にマッチした場合、その中身ごと丸ごとスキップされる。走査自体しないので高速)
#   - "/" を含むパターン → F:\FRB からの相対パス（"/" 区切り）に対してワイルドカードマッチ
#       ( * は任意文字列、? は任意1文字。PowerShell -like と同じ規則 )

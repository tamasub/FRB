# FRB Specification

Fishing Rod Benchmark (FRB) の基本仕様を定義する。

---

# 1. Purpose

FRBは  
釣り竿の「感度」を比較可能な形で記録するための  
ベンチマーク手法である。

ロッド感度は長い間  
主観的な評価に依存してきた。

FRBはそれを

- 再現可能
- 観測可能
- 比較可能

な形にすることを目的とする。

---

# 2. Basic Concept

FRBは

「同じ入力を与えれば  
ロッドごとに異なる振動応答が現れる」

という原理に基づく。

この振動応答を観察・記録することで  
ロッド感度の特徴を比較する。

---

# 3. Test Input

FRBでは主に以下の入力を使用する。

### 床擦り

ルアーまたは治具を床面に接触させ  
一定条件で擦ることで振動を発生させる。

これはFRBの基本テストである。

---

# 4. Measurement

振動の観測には以下の方法を用いる。

- マイク
- 加速度センサー（将来）
- FFT解析

観測データから以下を記録する。

- 主ピーク周波数
- 周波数帯域比率
- スペクトル構造

---

# 5. Subjective Notes

FRBでは数値だけでなく  
体感メモも重要なデータとして扱う。

例：

- 音が太い
- シャープ
- 金属的
- 手元に来る

これらは `FRB_TERMS.md` に定義された用語を用いる。

---

# 6. Reproducibility

FRBは  
室内環境で再現可能なテストを重視する。

これにより

- ロッド比較
- 改造効果
- 構造差

を検証できる。

---

# 7. Current Status

FRBは開発中のベンチマークであり  
仕様は今後更新される。

---

# 8. Philosophy

FRBの基本理念：

感度は分かち合って初めて本物になる。
